## How to Open the Assignment Notebook

1. **Open the assignment notebook in Google Colab.** This repo contains a file named `assignment_0.ipynb`. We'll launch it in Google Colab, where you can write and run code.

   - **Option A (Recommended)** — Open Google Colab directly:
     1. Open https://colab.research.google.com/
     2. Click **See All** in the top right corner of the page. This will open a pop-up window. 
     3. Click the **GitHub** tab in the pop-up
     4. For the repository, choose `yse-eds-cert/yse-eds-cert-practice-set-0-<yourUserNameHere>`, replacing `<yourUserNameHere>` with *your* GitHub username
     5. Click `assignment_0.ipynb`

   - **Option B** — Edit the following link with your GitHub username, replacing `<yourUserNameHere>` with *your* GitHub username, and follow that edited link:
     `https://colab.research.google.com/github/yse-eds-cert/yse-eds-cert-practice-set-0-<yourUserNameHere>/blob/main/assignment_0.ipynb`

2. In Colab, go to **File → Save a copy in Drive** — this creates an autosaving working copy in your Google Drive. Do all your work there, so that you always have a copy backed up in your personal Google Drive. You may delete "Copy of" from the file name.
3. Follow the instructions in the notebook to **Complete the Assignment**. Be sure to follow the instructions at the very beginning of the notebook that tell you how to make sure the notebook expects R code instead of Python code.
4. When finished, submit by going **File → Save a copy in GitHub** → select your personal assignment repo (`yse-eds-cert/yse-eds-cert-practice-set-0-<yourUserNameHere>`) and "push" your final work back to your GitHub repo. **Be sure to save to *YOUR* personal repo by correctly replacing `<yourUserNameHere>`**

> **Why save to Drive first?** Colab autosaves to Google Drive but does **not** autosave to GitHub. Saving to Drive protects your work-in-progress. Saving to GitHub is the manual submission step.
